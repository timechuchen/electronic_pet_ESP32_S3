# 兰洛桌宠 1.2.0

本版包含 VRM 模型导入、FBX 动作导入、AI 文字聊天、系统中文朗读，以及原有的动作、表情、预设、摄像头与音乐跟随。运行环境与人物资源均已内置，无需安装 Python、Node.js 或打开浏览器。

## 启动

先退出旧版桌宠，再运行新版。首次启动显示透明人物，鼠标移到人物上方可打开「设置」或「聊天」。从菜单栏／托盘可以恢复鼠标穿透、显示人物或退出。

- **macOS Apple Silicon（M 系列）**：macOS 13 或以上，解压 `兰洛桌宠-1.2.0-macOS-AppleSilicon.zip`，打开 `兰洛桌宠.app`。也可以将整个 `.app` 拖到“应用程序”。本包不适用于 Intel Mac。
- **Windows x64**：面向 Windows 10/11 64 位，完整解压 `兰洛桌宠-1.2.0-Windows-x64.zip`，进入 `Lanluo-1.2.0-Windows`，双击 `Lanluo.exe`。这是便携应用，须保留同目录的 resources、DLL 等文件，不能单独复制 exe。

macOS 应用采用本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证；Windows 未做发布者代码签名。其他电脑可能显示系统安全提示。确认文件来自可信来源后按系统提示处理，不需要关闭系统全局安全保护。

## 自定义模型与动作

进入「设置 → 模型与 FBX 动作」：

1. **角色模型**：导入 VRM 0.x / 1.0 文件，在列表中选择后点击「应用模型」。桌宠和设置窗口同步切换，重启后保留；可随时「恢复兰洛」。
2. **FBX 动作**：选择文件、动画片段，检查自动识别的骨骼映射；非标准命名可手动对应。点击「保存 FBX 动作」，然后点击动作播放。支持速度、暂停与循环。
3. 默认「原地播放」，保留跳跃高度。关闭该选项可保留水平轨迹，但长距离运动可能走出视野。

单文件最大 128 MB，模型库最多 16 个，FBX 动作最多 64 个片段。FBX 必须包含可映射到人形骨骼的动画，不能保证所有非人形骨架或未烘焙约束都兼容。VRM 纹理需内嵌。详见同目录《模型与FBX导入说明.md》。

## AI 聊天

点击桌宠的「聊天」或使用 Cmd/Ctrl + J，在「连接设置」填入自己的 DeepSeek API Key，保存并测试连接。聊天需要联网及相应 API 账户额度；普通桌宠、模型和动作导入不需要联网。

Key 使用系统密钥服务加密保存；聊天记录保存在本机，可在聊天窗口清空。系统中文朗读可选，需要系统已有本地中文声音；没有声音时仍能文字聊天。尚未内置麦克风转写。详细功能与数据边界见《AI接入说明.md》。发布包不包含开发者的 Key 或聊天记录。

## 数据与升级

1.2.0 继续使用 1.1 系列用户目录，已有配置、动作和聊天记录可保留：

- Mac：`~/Library/Application Support/LanluoDesktop-v1.1/`
- Windows：`%APPDATA%\LanluoDesktop-v1.1\`

自定义模型／FBX 保存在该目录的 `assets/`，不会写入应用安装目录。旧版发布包仍保留在项目原来的发布目录。

## 验证范围

macOS 在当前 Apple Silicon 机器上执行打包版的启动、导入与切换、双窗口同步、动作库、聊天和重启测试。聊天接口使用模拟响应，不会使用用户真实 Key 或产生付费 API 请求。实际摄像头、系统音频权限与真人语音效果仍依赖设备和用户授权。

Windows 已完成交叉打包、x64 可执行文件、版本号、运行环境与资源完整性检查；当前没有 Windows 实机，尚未验证 Windows 上的启动、系统加密、摄像头、音频回环及中文声音。

压缩包校验值见 `SHA256SUMS.txt`，具体结果见《构建与验证记录.json》。

### 本次 macOS 聊天验证的限制

打包版在真实系统密钥存储步骤两次超过 30 秒，测试没有写出 Key 配置，因此未将“系统加密保存可用”标记为通过。随后只在测试进程中替换存储接口，完成聊天窗口、模拟回复、动作联动、取消、错误恢复、重启和清空记录验证；发布应用仍使用原来的系统加密实现，没有明文回退，也没有包含测试替身。

实际使用时如出现钥匙串授权提示，需要由使用者在系统界面处理；若保存一直无响应，关闭并重新打开应用后再检查系统钥匙串状态。当前未完成这一步的实机确认。Electron 官方文档说明，ad-hoc 签名或更新后签名变化可能导致钥匙串重新授权，但本次未读到系统弹窗，不能断定超时的唯一原因。参考 [Electron 代码签名与系统 API](https://www.electronjs.org/docs/latest/tutorial/code-signing)。
