# 开发板固件与工具

本仓库只维护 ESP32-S3 固件、离线素材、中文字库和相关开发工具。桌宠客户端、三维渲染、AI、系统语音及用户配置在 [electronic_pet_PC](https://github.com/timechuchen/electronic_pet_PC) 维护。

## 编译与烧录

已验证 SDK 为 **ESP-IDF v6.1.1**，目标固定为 `esp32s3`。依赖版本见 `main/idf_component.yml` 和 `dependencies.lock`，使用 32 MB Flash、8 MB PSRAM。

```bash
# 先在本机激活 ESP-IDF，再进入项目根目录
idf.py build
idf.py -p YOUR_SERIAL_PORT flash
```

Mac 也可运行 `编译并烧录.command`，自动寻找 USB 串口；如未激活 SDK，脚本尝试使用 `PET_IDF_ACTIVATE` 指定的激活脚本或本机 EIM v6.1.1 路径。Windows 使用 [Windows 烧录说明](../Windows烧录说明.md) 中的源码编译入口。

烧录和诊断前请退出 PC 客户端或暂停自动连接，关闭串口监视器。仅编译不会访问开发板，不需要连接 USB。固件编译不依赖 PC 源码、Node.js 或桌宠运行环境。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `main/main.c` | JPEG 解码、USB 协议、扬声器与 UI 回调连接 |
| `main/pet_ui.c` / `main/pet_ui.h` | 圆屏布局、触摸、陪伴/唤醒状态、动画和空闲计时 |
| `main/ui_text.h` | 中文文案 |
| `main/pet_font_zh_*.c` | 16/20/28 像素中文子集字库 |
| `main/pet_assets.h` | 离线帧偏移与动作索引 |
| `assets/pet_frames.bin` | 离线 JPEG 帧数据 |
| `assets/manifest.json` | 动作、帧数与分辨率 |
| `tools/build_fonts.cjs` | 字库生成及字符覆盖检查 |
| `tools/export_assets.cjs` | 调用外部 PC 渲染器生成开发板离线素材 |
| `tools/board_usb.py` | 独立 USB 诊断协议及 RGB565 截图转换 |
| `tools/check_board.py` | 固件实机检查和截图 |
| `tools/windows_flash.py` | Windows 编译与烧录 |
| `artifacts/` | 本机检查结果，Git 忽略 |

## 修改中文文案

修改 `main/ui_text.h` 后执行：

```bash
idf.py reconfigure
npm ci --prefix tools/font-tool
node tools/build_fonts.cjs
idf.py build
```

字体源来自 LVGL 组件自带的思源黑体。生成器检查文案字符是否均在子集中；许可证保留于 `assets/fonts/`。未修改文案时无需安装 Node.js 或重新生成字库。

## 重新导出离线动画

现有素材已包含在仓库中，日常编译无需导出。只有更新内置动画时才需要单独克隆 PC 项目，在其 `packaging/` 目录运行 `npm ci`，并准备 Python 3.10+、Node.js 22.12+ 和本机 Chrome。

在开发板项目根目录执行，路径请替换为本机 PC 项目根目录（其中应有 `packaging/backend/app.py`）：

```bash
node tools/export_assets.cjs --pc-root /path/to/electronic_pet_PC --check
node tools/export_assets.cjs --pc-root /path/to/electronic_pet_PC
idf.py build
```

`--check` 只启动隔离的渲染服务并验证 JPEG 输出，不覆盖素材。可用 `--python /path/to/python3` 指定解释器，或用 `--output-dir /path/to/output` 将新素材导出到另一个目录。

导出器在本机随机端口启动 PC 渲染服务，使用临时资料目录，不读取个人桌宠设置。默认导出内置兰洛的待机及 9 组动作，8 帧/秒、320×320；完整导出后更新 `assets/` 和 `main/pet_assets.h`。原始 VRM/FBX、网页引擎和 Electron 不复制到此仓库。更换离线模型需在外部 PC 渲染源中准备对应素材。

## 逻辑检查与实机诊断

在 ESP-IDF Python 环境中执行：

```bash
python -B -m unittest discover -s tools -p 'test_*.py'
```

独立使用诊断脚本时可建立虚拟环境并安装串口依赖：

```bash
python3 -m venv .venv
# 激活 .venv 后
python -m pip install -r tools/requirements.txt
python tools/check_board.py --help
python tools/check_board.py --port YOUR_SERIAL_PORT --chinese
```

自动发现仅匹配原生 USB `303A:1001`，存在多块板时请显式指定 `--port`。脚本检查状态、错误 CRC、错误/有效 JPEG、离线回退、动作、暂停和真实 466×466 屏幕截图；`--chinese` 额外检查五页按钮和聊天提示。结果保存到 `artifacts/firmware-check.json` 和 PNG 图片，可用 `--output` 改变目录。

诊断会短暂改变板上画面和动作，结束时发送复位动作命令；不会烧录或擦除固件。不要与 PC 客户端或串口监视器同时打开同一串口。截图转换仅使用 Python 标准库，不依赖 Mac 的 sips 或 PC 客户端。

## 陪伴 UI 与桌面验证

UI 状态与芯片节能状态分开：开机 `ambient=true`，菜单隐藏，宠物缩放值 344/256（旧版 230/256）；唤醒后为 256/256。缩放与位置用 320ms 缓动过渡，反向操作会取消旧过渡。文字分为 28px 名称、20px 反馈/按钮与 16px 状态/提示，按钮间距 10px，保留圆屏边缘空间。

- 轻触待机屏只唤醒，不发送 PC 动作；唤醒后再次轻触才微笑。
- 唤醒后长按重置并收起菜单，对旧 PC 仍发送 `reset`。
- `PET_UI_IDLE_MS` 默认 20,000ms。只有触摸或明确的动作命令重置计时，持续 JPEG 不唤醒 UI。
- 离线长动作播放完再收起；待机每隔约 6.5–9.9 秒插入一个轻动作，不发 USB 事件。
- “暂停”保持冻结，自动进入陪伴模式也不解除；`sleep`/长按会解除暂停。
- 不改 JPEG 协议尺寸、不增加动画素材、不动态分配每帧 UI 对象。动画继续按 8fps 解码；放大后的实际刷屏开销仍需实机确认。

可直接用项目依赖中的同版本 LVGL 编译桌面无窗口测试，无需开发板。需要 CMake、C/C++ 编译器和 libjpeg 开发库（macOS 可使用已安装的 Homebrew jpeg-turbo）：

```bash
cmake -S tools/ui_preview -B artifacts/ui-preview-build -DCMAKE_BUILD_TYPE=Debug
# macOS 找不到 JPEG 时，可额外传 -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/jpeg-turbo
cmake --build artifacts/ui-preview-build -j 8
ctest --test-dir artifacts/ui-preview-build --output-on-failure
```

测试直接编译 `pet_ui.c`，解码固件 JPEG 素材并输入 LVGL 指针事件。覆盖首次触摸不误操作、长按/释放、五页按钮、暂停恢复、超时、24 秒动作、待机自主动作、联机断开与快速反向过渡；生成 `ambient.ppm`、`awake.ppm`、各页及聊天截图。它验证布局和状态，不代表板上帧率、功耗或真实触摸已验收。README 的新图由该渲染器导出；原有 `chinese-interface.png` 保留为历史实机记录。

## USB 协议

每包为 16 字节小端头 `<4sIII>`（`LPET`、类型、序号、长度），随后是 payload 和 4 字节小端 `zlib.crc32(payload)`。最大 payload 为 98,304 字节，发送方应逐包等待匹配序号的 ACK。

| 类型 | payload |
| --- | --- |
| 1 | 320×320 JPEG |
| 2 | 不超过 8192 字节的有符号 16 位小端、16 kHz 单声道 PCM |
| 3 | 小于 64 字节的诊断或动作字符串，如 `status`、`wave`、`reset` |
| 4 | 音频结束 |

类型 3 新增 `wake`（仅展开菜单）与 `sleep`（恢复默认动作并收起菜单）命令，原有动作、`pause`、`reset`、`offline`、`snapshot` 等保留。`PET_STATUS` 额外返回 `ambient` 与从 0 开始的 `page`，旧字段不变。未知动作返回 `ok=false`，不唤醒。

设备输出 `PET_ACK`、`PET_EVENT`、`PET_STATUS` JSON 行。串口读操作可能返回半行，需要缓存到换行符后再解析。`snapshot` 返回 `PET_SNAPSHOT width height stride size` 行及 RGB565 二进制数据，应先按指定长度读取，再解析后续 ACK。

开发板约 2.5 秒收不到有效联机画面时回到离线模式。曾出现离线动画正常而 USB 无响应的情况，拔插 USB 或按 RESET 后恢复；若再次发生，先恢复连接，不必立即重新烧录。

客户端联机、AI 和系统语音的测试在 PC 项目维护。角色素材保留原有授权范围，字体与固件依赖保留各自许可证。
